All example files are in `public/assets/pstack-search-repair/`.
The source files and feature map are hand-authored teaching fixtures.
The evidence JSON files were generated by real local CLI execution.
No pstack model workflow, skill-generation workflow, paid API call, remote
message, commit, PR, or publication was performed.

The example has no external dependencies. Commands can run directly from
the repository root:

```sh
node public/assets/pstack-search-repair/verify.mjs task-cli.before.mjs evidence-before.json
node public/assets/pstack-search-repair/verify.mjs task-cli.mjs evidence-after.json
```

The runner resolves files relative to its own directory, spawns each CLI
command without a shell, checks stdout, stderr, and exit codes, and confirms
the fixture was not modified.
