截至 2026-10-16，Kimi Code 没有单独的套餐，它包含在 Kimi 会员的 Plus 及以上档位里：国内版 Plus 每月 99 元，Pro 每月 199 元，Max 每月 699 元；最便宜的 Go（每月 49 元）不包含 Kimi Code。

## 国内版价格

| 档位 | 按月付 | 按年付（总价） | 折合每月 | Kimi Code |
| --- | --- | --- | --- | --- |
| Go | 49 元 | 468 元 | 39 元 | 不含 |
| Plus | 99 元 | 948 元 | 79 元 | 包含 |
| Pro | 199 元 | 1,908 元 | 159 元 | 包含 |
| Max | 699 元 | 6,708 元 | 559 元 | 包含 |

几档之间的区别主要在 Agent 额度：Plus 是 2 倍，Pro 是 4 倍，Max 是 14 倍。Pro 起还有 Goal Mode、专属 Kimi Claw，以及 K3 模型的 1M 上下文和 HighSpeed 通道。

国际版是另一套价格，四档都包含 Kimi Code：Plus 每月 19 美元，Pro 39 美元，Max 99 美元，Ultra 199 美元。

## 用量怎么限制

新版套餐的 Kimi Code 只有一个滚动的 5 小时窗口，短时间请求太多会被限流，窗口滚过去就自动恢复；之前的周上限已经取消。不过它和其他 Kimi 功能共用每月的总额度，月额度用完，Kimi Code 也会被冻结，直到下月重置或者升级。

老会员（Andante、Moderato 等旧档名）保持原规则不变，仍然有 5 小时窗口加每 7 天刷新的周额度。

我的看法：只写代码的话 Plus 就够起步，真正决定体验的是 5 小时窗口和月总额度，不是档位名字。如果你同时重度用 Kimi 的研究和办公 Agent，它们会和写代码抢同一个月额度，这时候再考虑 Pro。

价格以 [Kimi 会员说明](https://www.kimi.com/en/help/membership/membership-overview) 和 [Kimi Code 会员权益文档](https://www.kimi.com/code/docs/en/kimi-code/membership) 为准。
