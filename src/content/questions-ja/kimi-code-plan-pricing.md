2026-10-16 時点で、Kimi Code 単体のプランはなく、Kimi 会員プランに含まれています。国際版は Plus（月 19 ドル）、Pro（39 ドル）、Max（99 ドル）、Ultra（199 ドル）の 4 プランすべてで使えます。中国版は Plus（月 99 元）以上が対象で、最安の Go（49 元）には含まれません。

新プランの Kimi Code には 5 時間のローリング制限だけがあり、週ごとの上限は廃止されました。ただし会員全体で共有する月間の総枠を使い切ると、リセットかアップグレードまで Kimi Code も止まります。旧プランは 5 時間制限と週ごとの枠が引き続き適用されます。

最新の条件は [Kimi の料金ページ](https://www.kimi.ai/help/membership/membership-pricing) と [Kimi Code 会員ドキュメント](https://www.kimi.com/code/docs/en/kimi-code/membership) で確認してください。
